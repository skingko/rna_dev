## 发现的实现缺口

学习入口原来将历史候选的证据 ID 合并后永久视为已尝试，未同时比较证据内容、模型、基线和评估运行时；因此修复运行时之后仍可能被旧失败拦住。真实评估路径也没有更新 `lastEvaluatedAt`。这些是可复现的缺口，但本次已有新 ID 证据尚未被覆盖，不能把它们称为近期没有选择学习的唯一原因。

主动决策缺少独立的学习状态摘要，无法直接看到近期候选及其失败阶段。版本页同样只显示旧候选，缺少当前自动进化开关、最近判断和下一次复查。取消结果还曾统一记录为项目上下文变化，丢失宿主给出的更具体原因。
